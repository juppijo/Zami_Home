Wenn du auf [ ⬇️ HTML-Datei speichern ] klickst, generiert die App eine nagelneue .html-Datei, in die deine verschlüsselten Daten und dein Master-Passwort-Hash direkt in den Code eingebettet sind. Wenn du diese heruntergeladene HTML-Datei auf einen USB-Stick ziehst, per E-Mail verschickst oder auf GitHub hochlädst und auf irgendeinem anderen PC öffnest, weiß die Datei sofort: „Ich kenne mein Passwort bereits!“ – und zeigt dir direkt die Maske zum Anmelden. index.html [generated with web_code_canvas tool] Was kann die neue Self-Contained-Funktion? [ ⬇️ HTML-Datei speichern ] Button: Klicke im eingeloggten Zustand einfach auf diesen Button. Die App nimmt ihren gesamten Quellcode, baut deine aktuell verschlüsselten Notizen sowie dein Verschlüsselungs-Salt direkt als gespeicherten Zustand in den Code ein und lädt eine neue Datei (z. B. meine-notizen-app.html) herunter. Verhalten auf jedem neuen PC / Browser: Öffnest du diese heruntergeladene .html-Datei auf einem anderen Computer, erkennt sie sofort, dass sie bereits eingerichtete Daten enthält. Sie fragt direkt nach dem Anmelden mit deinem bestehenden Master-Passwort – eine Neu-Registrierung ist nicht mehr nötig! Keine separaten JSON-Dateien nötig: Du brauchst keine extra Backups mehr mitzuschleppen. Die .html-Datei ist deine komplette Anwendung inklusive Datenbank.
